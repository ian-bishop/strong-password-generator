How the Password Generator Works

This password generator creates random passwords directly inside your web browser. It uses the Web Crypto API and crypto.getRandomValues() to obtain cryptographically strong random values.

Unlike generators that rely on Math.random(), the Web Crypto API is designed for applications that require stronger randomness.

The password is generated locally on your device. This page does not need to send the generated password to a server.

What Makes a Strong Password?

Password strength depends on factors including password length, randomness and the size of the character set used. Increasing the password length generally makes a randomly generated password substantially more difficult to guess through brute-force attempts.

You can configure this generator to include uppercase letters, lowercase letters, numbers and symbols. When a character type is selected, the generator guarantees that at least one character from that category appears in the generated password.

How Long Should a Password Be?

For accounts that support longer passwords, a randomly generated password of 16 characters or more provides a large number of possible combinations. This generator defaults to 20 characters and supports passwords up to 128 characters.

Different websites have different password requirements, so you can adjust the length and character types to match the requirements of the account you're creating.

Are Passwords Stored?

No password storage is required for this generator to work. Password generation takes place locally using JavaScript running in your browser.

Reloading or closing the page removes the currently generated password from the generator.

Frequently Asked Questions

Is this password generator secure?

The generator uses the browser's Web Crypto API rather than Math.random() for random-number generation. Passwords are generated locally in your browser.

Does the password leave my computer?

The generator does not need to transmit the generated password to a server. Password creation occurs locally through JavaScript running in your browser.

Can I generate passwords without symbols?

Yes. Uncheck the Symbols option before generating the password. You can independently enable or disable uppercase letters, lowercase letters, numbers and symbols.

What is the maximum password length?

This generator supports passwords between 4 and 128 characters.
